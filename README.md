# MediaDock

Windows 로컬 전용 **실제로 동작하는** yt-dlp + FFmpeg 미디어 다운로드 웹앱입니다. 브라우저는 UI이며 다운로드·변환·파일·SQLite 기록은 Python 백엔드가 관리합니다. 모든 작업은 **백엔드가 실행되는 컴퓨터의 CPU·디스크·네트워크**를 사용합니다.

## 실행

이 작업 폴더에는 의존성과 Windows x64용 FFmpeg/ffprobe가 설치되어 있습니다.

1. `start.cmd`를 더블클릭합니다. 또는 PowerShell에서 `./start.ps1`을 실행합니다.
2. 브라우저에서 **http://127.0.0.1:8765** 에 접속합니다.
3. 링크를 붙여넣으면 실제 메타데이터를 조회합니다. 재생목록은 항목을 선택한 뒤 다운로드합니다.
4. 항목의 **출력 옵션**에서 영상·음원·화질·프레임률·자막·썸네일·구간을 정합니다.
5. 오른쪽 **저장 설정**을 저장하거나, 다운로드 버튼으로 현재 저장 설정과 함께 작업을 등록합니다.

서버가 이미 실행 중이면 다시 실행할 필요가 없습니다. 브라우저만 닫으면 작업은 계속되며, 서버 콘솔에서 Ctrl+C를 누르면 진행 작업과 자식 프로세스를 취소하고 종료합니다. 비정상 종료 시 진행 중이던 기록은 다음 실행 때 `중단됨`으로 바뀌며 재시도할 수 있습니다. 완료 파일은 지우지 않습니다.

로컬 루프백에만 바인딩합니다. 모바일 **화면 크기**에서도 모든 기능을 사용할 수 있지만, 별도 휴대폰의 LAN 접속은 허용하지 않습니다. 이 앱은 사용자 격리·공개 서비스용 보안·자동 삭제를 구현한 공개 서버가 아닙니다.

## 새 컴퓨터에 설치

Python 3.10 이상(검증: 3.12.10), Node.js(검증: 24.12.0)가 필요합니다. Windows x64에서:

```powershell
./setup.ps1
./start.ps1
```

PowerShell 실행 정책으로 스크립트를 실행할 수 없으면 터미널에서 다음 명령을 개별 실행합니다. 시스템 실행 정책을 변경할 필요는 없습니다.

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
./.venv/Scripts/python.exe scripts/setup_tools.py
./.venv/Scripts/python.exe scripts/check_tools.py
./.venv/Scripts/python.exe run.py
```

`setup_tools.py`는 yt-dlp 프로젝트의 공식 Windows GPL FFmpeg 빌드를 내려받고 GitHub 자산 SHA256을 확인합니다. yt-dlp는 공식 PyPI의 `yt-dlp[default]`로 설치합니다. JavaScript 실행은 설치된 Node.js와 `yt-dlp-ejs`를 사용합니다. 원격 JavaScript 컴포넌트를 임의로 받아 실행하는 옵션은 사용하지 않습니다.

## 설정과 파일

| 경로 | 내용 |
|---|---|
| `config.json` | 앱 이름, 포트, 절대 저장 경로, 폴더/파일명 규칙, 제한, 기본 출력 옵션 |
| `downloads/` | 기본 완료 파일 저장 위치 |
| `data/history.sqlite3` | 작업·진행률·파일 위치·오류·일시적 조회 메타데이터 |
| `data/work/<작업 ID>/` | 작업 중 임시 원본·변환 파일. 작업 종료 시 해당 작업 폴더만 정리 |
| `tools/provenance.json` | 실제 다운로드 URL, SHA256, 사용 버전과 빌드 설정 |
| `tools/capabilities.json` | 실제 인코더·필터 지원 점검 결과 |
| `tools/help/` | 설치 버전의 yt-dlp/FFmpeg/ffprobe 도움말과 라이선스 출력 |
| `docs/toolchain.json` | 구현 시점에 확인한 도구 출처·버전 사본 |

앱 이름은 즉시 반영되며 포트는 재시작 후 적용됩니다. 기본 포트는 8765입니다. 저장 경로는 로컬 절대 경로만 받으며 UNC 네트워크 경로는 지원하지 않습니다. 저장 폴더는 실제 쓰기 가능 여부를 확인합니다. 하위 폴더는 `강의/디자인` 같은 상대 경로입니다.

파일명 변수는 `{title}`, `{id}`, `{channel}`, `{date}`입니다. 유효하지 않은 파일명 문자를 정리하고 뒤에 짧은 작업 ID를 붙여 파일을 덮어쓰지 않습니다. 작업을 등록할 때 저장 설정을 고정하므로 이후 설정 변경이 기존 대기 작업의 목적지를 바꾸지 않습니다. 동시 작업 제한은 즉시, 속도 제한은 새로 시작하는 작업부터 적용됩니다. 속도 제한은 **작업당 KiB/s**, 0은 무제한이며 작업당 HLS 조각 동시 다운로드는 1개입니다.

`출력 옵션 기억하기`를 켜면 마지막으로 바꾼 항목의 출력 옵션을 새 항목 기본값으로 저장합니다. 끄면 다음 앱 실행에서 기본 출력 옵션으로 돌아갑니다. 저장 위치·작업 제한·기록은 이 옵션과 관계없이 유지됩니다. 재생목록 안에서도 항목별 설정을 바꿀 수 있습니다.

## 출력 동작

- **화질**: 원본을 먼저 표시하고 실제 지원되는 낮은 해상도를 내림차순으로 표시합니다. 프레임률도 선택한 해상도에 제공되는 값만 표시합니다. 없는 화질로 자동 대체하거나 업스케일하지 않습니다.
- **영상**: 자동은 가능한 원본 컨테이너, MP4/MKV는 지정 컨테이너를 사용합니다. 호환되는 스트림은 복사합니다. MP4에 맞지 않는 영상·음원은 H.264/AAC로 변환합니다. 분리된 최고 영상+음원은 yt-dlp가 합칩니다.
- **음원**: MP3 VBR 품질 0–9 또는 CBR 64–320 kbps, M4A AAC 256 kbps, 원본 코덱 추출. 원본 음원도 구간을 자르면 같은 코덱으로 재인코딩합니다. 지원되지 않는 원본 코덱의 구간 저장은 명시적으로 실패하고 MP3/M4A 선택을 안내합니다.
- **자막**: 제작자 자막과 자동 생성 자막을 구분해 해당 언어만 요청합니다. 별도 UTF-8 SRT, 영상 내장(MP4는 mov_text, MKV는 SRT), 영상 고정(libass)으로 처리합니다. 음원에는 별도 SRT만 지원합니다. 자막 없는 링크는 이를 표시합니다.
- **구간**: 초 또는 HH:MM:SS를 입력합니다. 원본 전체를 내려받은 뒤 정확한 탐색·재인코딩으로 자릅니다. 자막의 겹치는 부분을 잘라 0초부터 다시 맞춥니다. 자막 내장·고정 모드에서 해당 구간에 자막이 없으면 안내 오류를 반환합니다.
- **원본 썸네일**: 제공자가 준 파일을 원래 확장자로 저장합니다. 제공하지 않거나 다운로드에 실패하면 썸네일 저장이 성공한 것처럼 처리하지 않습니다.
- **용량**: 제공된 파일 크기, 사이트의 추정 크기, 또는 비트레이트×길이로만 계산합니다. 근거가 없으면 **정보 없음**입니다. 표시 값은 전체 원본 다운로드 기준이며 재인코딩·구간·자막 이후 최종 크기는 다릅니다.
- **재생목록**: 최대 200개까지 조회합니다. 제한에 도달하면 화면에 표시합니다. 전체/개별 선택을 지원하며 선택한 항목만 정보 조회 후 대기열에 추가합니다.
- **중복 방지**: 사이트 추출기+영상 ID, 정규화된 출력 옵션, 저장 경로/규칙을 함께 비교합니다. 같은 진행·대기·완료 작업은 중복 등록하지 않습니다. 실패·취소는 재시도할 수 있습니다. 완료 파일이 외부에서 삭제됐다면 동일 설정의 새 작업을 등록할 수 있습니다.
- **진행률**: yt-dlp의 JSON progress-template, FFmpeg의 `out_time_us`를 읽습니다. 각 스트림 다운로드와 변환 단계별 진행률이며 가짜 전체 진행률은 없습니다. 크기/길이를 모르면 진행 중으로 표시합니다. 재시도는 해당 작업을 처음부터 수행합니다.

## 입력·실행 보호

HTTP(S) 링크만 받고 사용자명·비밀번호가 들어간 URL, 제어 문자, 경로 이탈과 임의 파일명 템플릿을 거부합니다. 실행 파일과 인자를 분리한 `subprocess.Popen`을 사용하며 쉘은 사용하지 않습니다. yt-dlp의 사용자 설정과 플러그인 검색을 끕니다. 파일 다운로드 API는 완료 기록에 등록된 경로만 제공합니다.

루프백 클라이언트와 정확한 Host를 확인하고, 다른 Origin/Sec-Fetch-Site의 요청을 차단합니다. 변경 요청에는 실행마다 생성한 토큰이 필요합니다. CORS를 열지 않습니다. 요청 크기·조회 동시성·조회 시간·작업 시간을 제한합니다. Windows 취소는 `taskkill /T /F`로 해당 프로세스 트리를 종료하고 FFprobe 검사도 취소 대상에 포함합니다. 동일 데이터 폴더에서 두 작업 스케줄러가 실행되지 않도록 OS 파일 잠금을 사용합니다.

본인 로컬 미디어 서버도 사용할 수 있으므로 사설망 URL 자체는 막지 않습니다. **공개 서비스로 호스트를 변경해서 사용하면 안 됩니다.** 공개 배포에는 별도의 사용자 인증·파일 격리·사용량 제한·리디렉션/DNS를 포함한 SSRF 방어·자동 삭제 설계가 필요합니다.

## 검증

검증 결과와 미검증 범위는 [docs/VALIDATION.md](docs/VALIDATION.md)에 있습니다. 테스트 미디어는 FFmpeg로 직접 생성한 색상/동작 패턴과 사인파, 자체 작성 영문 자막입니다. 앱에 가짜 작업을 시드하지 않습니다.

```powershell
./.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./.venv/Scripts/python.exe -m pytest -q --junitxml=test-results/pytest.xml
```

수동 브라우저 검증용 자체 미디어 서버:

```powershell
./.venv/Scripts/python.exe scripts/fixture_server.py
# 앱에 http://127.0.0.1:9876/single.html 또는 /playlist.html 입력
```

## 제한 사항

- 지원 사이트 목록에 있어도 사이트 변경·지역 제한·로그인·봇 확인·요청 제한 때문에 실패할 수 있습니다. 오류 원문을 작업 상세에서 확인하세요. 쿠키 업로드·브라우저 쿠키 추출·DRM 우회는 구현하지 않았습니다.
- 진행 중인 라이브 방송은 지원하지 않습니다. 종료된 영상만 사용하세요.
- 자막·해상도·프레임률·길이는 사이트가 제공한 정보에 의존합니다. 변환 중 한글 폰트는 Windows 설치 폰트를 사용합니다. 선택한 출력 형식에 따라 HDR/10-bit 영상의 구간 재인코딩이 8-bit H.264로 바뀔 수 있습니다. 원본 전체의 무변환 저장과 구간 변환은 화질 보존 특성이 다릅니다.
- 정확한 구간 처리를 위해 전체 원본과 결과물을 함께 둘 디스크 공간이 필요합니다. 디스크 부족·쓰기 권한·파일 잠금 오류는 작업 실패로 남습니다.
- 완료 파일은 자동 삭제하지 않습니다. 탐색기에서 이동·삭제해도 기록은 유지되며 파일 받기는 안내 오류를 냅니다. 작업 내역 삭제 UI는 제공하지 않습니다.
- MP3/M4A는 손실 압축입니다. M4A는 AAC를 사용합니다. 원본 음원은 구간이 없을 때 무변환으로 추출합니다.
- 전체 미디어 처리 시간 제한은 프로세스당 24시간, 메타데이터 조회 120초, FFprobe 검사 30초입니다. 작업별 속도 제한은 yt-dlp 네이티브 다운로드에 적용됩니다. 사이트가 강제하는 외부 다운로드 방식에는 제한이 완전히 적용되지 않을 수 있습니다.
