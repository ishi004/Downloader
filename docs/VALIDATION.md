- 데스크톱 1440×1000: 네이비 사이드바, 실시간 통계, 링크 입력, 항목별 옵션, 우측 저장 설정 확인.
- 모바일 390×844: 문서 너비와 스크롤 너비가 동일하여 가로 넘침이 없음. 네비게이션, 링크 입력, 출력 옵션, 내역, 저장 설정, 엔진 상태 대화상자에 접근 가능.
- 실제 UI에서 링크 조회 → MP4/SRT/원본 JPG 선택 → 시작 2초·종료 6초 입력 → 다운로드 실행 확인.
- 결과: `MediaDock authorized test (1)` 작업 1건, **정확히 4.0초 MP4**, 조정된 SRT, 원본 JPG. 완료 파일은 기본 `downloads/` 폴더에 있으며 테스트 영상임을 제목으로 구분합니다.
- 실제 작업 통계가 완료 1건과 합계 725.2 KiB로 반영됨을 확인했습니다. 이것은 실제 브라우저 실행 결과이며 샘플 통계가 아닙니다.
- 첫 검증에서 발견한 구간 입력값 초기화 문제를 수정하고 입력 2/6 유지 및 출력 4초로 재확인했습니다.
- 백엔드 취소 범위를 FFprobe까지 넓히는 과정에서 발생한 여러 줄 JSON 출력 잘림을 구조화 응답용 별도 버퍼로 수정하고 전체 29개 테스트를 다시 통과했습니다.
- 브라우저 개발자 로그에서 초기 화면의 JavaScript 오류 없음 확인.
- 모바일에서 재생목록 전체 선택 해제 후 2번만 체크하여 `1개 선택`과 다운로드 버튼 활성화 확인.

## 확인하지 않은 범위 / 제한

- 외부 서비스의 로그인·봇 확인·지역 제한을 우회하는 검증은 하지 않았습니다. YouTube를 포함한 모든 지원 사이트에서 항상 다운로드된다는 뜻은 아닙니다.
- 자동 생성 자막 언어 목록과 전용 yt-dlp 요청 옵션은 연결되어 있으나, 외부 서비스의 자동 생성 자막을 실제 내려받는 종단 검증은 하지 않았습니다. 자체 생성 fixture의 제작자 자막으로 자막 변환 파이프라인을 검증했습니다.
- 자막 고정 테스트는 실제 libass 인코딩 성공과 스트림을 검사합니다. 다양한 언어/폰트의 시각적 회귀 검사는 수행하지 않았습니다.
- HDR/10-bit, 장시간/대용량 영상, 모든 원본 음원 코덱 조합, 네트워크 단절/디스크 가득 참의 모든 조합은 별도 검증하지 않았습니다.
- 모바일 검증은 브라우저 viewport로 수행했습니다. 별도 휴대폰에서 LAN 접속하는 기능은 로컬 전용 설계상 없습니다.
- 공개 서비스용 인증·사용자 격리·공인 인터넷 노출은 범위에서 제외했습니다.
